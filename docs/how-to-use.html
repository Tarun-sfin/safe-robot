Safe Robot — How to Use

An automated tester that fills out the Safe Financial loan application by itself and runs it through to a decision.

What it does

Safe Robot opens a browser and drives the entire mini-loan application on its own — with a brand-new made-up applicant each time — injects a bank statement, and continues all the way to the final Submit. It is used to quickly test that the application journey works end to end.

What you need

  • A Windows 10 or 11 PC.
  • An internet connection (only needed the first time you run it).

Running it — step by step

  1. Unzip the whole folder first. Right-click the ZIP → Extract All… → pick a location (e.g. your Desktop). Do not run it from inside the ZIP — extract it first, or it will not work.
  2. Open the extracted SafeRobot folder and double-click SafeRobot.exe.
  3. If Windows shows a blue “Windows protected your PC” box, click More info → Run anyway. (This just means the app isn’t signed — it’s safe.)
  4. First run only: it automatically sets itself up (installs a private copy of Node, the dependencies, and the browser). This takes a few minutes and needs internet. The window may look busy or quiet for a bit — that’s normal.
  5. It asks Beta or Local — type 1 for Beta (or 2 for Local).
  6. A browser window opens and the robot drives the whole application. When it finishes, the window stays open with the result — press Enter to close it.
No exe? If your antivirus blocks SafeRobot.exe, you can instead double-click run-robot.bat in the same folder — it does exactly the same thing.

Choosing what it tests

Double-clicking runs the default (Beta, full flow). To choose options, open PowerShell in the folder and run:

CommandWhat it does
run-robot.ps1 -Target betaTest the Beta website
run-robot.ps1 -Target localTest a locally-running copy
run-robot.ps1 -Target beta -StopAtBankQuick demo — stops at the bank step
run-robot.ps1 -Target beta -HeadlessRun without a visible browser (report only)

Running the full end-to-end test

To go all the way to a decision, the robot injects a real bank statement. For a quick look, use -StopAtBank (above) — it needs no setup and stops right after the bank step. For the full run, place a real bank-statement file (the Postman request body) at fixtures/bank-statement.json inside the folder. A sample of the expected shape is included as fixtures/bank-statement.sample.json.

Good to know

  • Every run creates a real application on whichever site you pick — that’s intended.
  • A fresh random applicant is used each run, so it never clashes with a previous one.
  • After a run you can open the detailed report: run npx playwright show-report in the folder.

If something doesn’t work

  • Nothing happens / can’t download on first run: a work network may block the setup downloads — try a normal network, or ask IT to allow nodejs.org and npm.
  • It gets stuck on one screen: the website may have changed — let the team know which screen it stalled on.
  • Windows/antivirus blocks the exe: use run-robot.bat instead.
